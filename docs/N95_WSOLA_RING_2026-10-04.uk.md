# N95: WSOLA через native ring

Current shell уже містить SMLAD. Окремий matched cohort
[WSOLA68](N95_WSOLA_CURRENT_2026-10-04.md) його виміряв; нижче63 лишається
historical scalar comparison, samples не змішано.

Окремий candidate63 / host48 / protocol40 виконав pilot із 8 jobs і три
повні серії по 120 jobs. Усі offset, signed score і кількість перевірених
позицій збігаються зі scalar ARM reference для восьми аудіовипадків,
зокрема крайніх offset і tie case. У кожній job перевірено 1280 слів.
[Результати та журнали](evidence/2026-10-04/n95-wsola63-results.json).

Кільце має 16 KiB загалом. Job передає чотири input slots (880 signed
mono words і zero padding) та отримує один output slot. DSP використовує
власний 880-word scratch у контексті вузла. Native pages збережені між
brackets; ownership повертається ARM після completion та cache invalidate.
Delete/free/unmap/unreserve/close/FINAL0/EXIT0 успішні в усіх runs.
Шість перевірок stock clock до/після серій пройшли. Це snapshots;
безперервної перевірки DVFS усередині порцій немає.

ARM baseline — середнє 16 warm scalar calls; він чергується до/після
передачі. H+D вимірюється від початку пакування до читання результату,
включає cache operations і notifications. Коректність перевіряється поза
цим інтервалом. Aggregate nearest-rank p50: **A=1155.853 us**,
**H+D=1983.643 us**. Лише **16/360** paired samples мають H+D<A ще до
амортизації запуску. Це тест ядра, а не вимір прискорення емулятора.

Інструментований S=setup+teardown: p50 **828063 us**. Setup починається
до processor/DCD/task/buffer preparation, teardown охоплює повне очищення;
Log синхронно Write+Flush кожного рядка. Mapping і create окремо значно
коротші, тому загальний S не можна називати чистою ціною create або
мінімальною вартістю production integration. Причину всіх затримок цей
тест не розділяє. Для сценаріїв використано виміряний S відповідної серії.

Умова виграшу залишається max(H+D,W)+S/N < A+W, тобто обидві строгі
нерівності S/N<A і W>H+D+S/N−A. Цей host не виконує корисний ARM W під
час очікування DSP; сценарії W — пороги, не виміряний parallel speedup.
Поточний висновок: **залишити існуючий WSOLA**, стабільного blocking
виграшу в цих умовах немає. SMLAD baseline не виміряний; оцінку 135–200 us
не змішано з physical A. MDEC/SPU ring kernels ще не виміряні.

720 DCR reads у повних серіях: 0000, WPE=0; це стосується candidate63.
Helper містить тільки MOV port(#0x200),T0 і RET, без configuration writes.
[Instruction audit](evidence/2026-10-04/n95-wsola63-instruction-audit.json).
Повний independent OMAP2420 endpoint-publication contract досі відкритий.
Raw DSP ticks і CLK_countspms=164 збережено без перетворення в wall time.

**CPU usage не кваліфіковано:** 320/360 GetCpuTime deltas перевищують
відповідний transfer wall interval. Причина не встановлена; відсоток
offload CPU з цих значень не виводиться. Наступна окрема
[калібровка без DSP](N95_CPU_COUNTER_2026-10-04.md) відтворила delayed
slice accounting; потрібне довге aggregate window із settling boundaries.

GET/SHA-equal, c55stream/ocprobe PS0.
