# N95: read-only DCR diagnostic

N95 виконав окремий host47/candidate62/protocol39 pilot:8 exchanges по15
slots,120 повністю правильних пакетів. Перед і після кожного exchange
DSP прочитав I/O port0x200. Усі16 значень — **0000**, WPE(mask80)=0.
Це поточний вимір non-posted configuration; історичним54/61 runs його
не приписуємо. DSP/PRCM configuration не змінювали.

У завантажуваному DOFF helper `_ring_read_dcr` містить рівно6 bytes
`A45102004804`: `MOV port(#0x200),T0; RET`. Helper не має relocation;
compiler assembly викликає його до та після ring_exchange і записує
результати в notification words14/15 із marker dc01 уword13. Protocol39
відрізняє діагностику від звичайного38. Host і runner дозволяють цей режим
лише на N95; validator перевіряє усі frames, marker, WPE decode й lifecycle.
[Instruction audit](evidence/2026-10-04/n95-dcr62-instruction-audit.json),
[artifact proof](evidence/2026-10-04/n95-dcr62-artifacts.json).

Stock PRCM brackets до/після PASS; native pages незмінні, full-word checks,
wrap/carry, delete/free task/unmap/unreserve/free buffers/close/FINAL0/EXIT0.
Після pilot N95 originals5 повернуто й перевірено GET/SHA-equal; PS0.
Daemon startup tuple62209 не змінився. `startTick` не є phone boot ID.
[Measurement/restoration](evidence/2026-10-04/n95-dcr62-results.json).

D1 лишається in_progress: поточний WPE уже виміряний, але повний
OMAP2420 endpoint-memory/notification ordering contract ще не доведений.
[TI BIOS GBL reference](https://software-dl.ti.com/targetcontent/legacy_files/targetcontent/bios/bios_5_31/sabios-h16/docs/packages/ti/bios/doc/spru404m.pdf)
ідентифікує posted/non-posted вибір для OMAP2420; OMAP2420 TRM SWPU064
потрібний для точного endpoint contract. OMAP2423 public addendum
SWPU087C лише відсилає DSP chapter до2420 TRM. Інші C55x EMIF manuals
не є доказом саме цього OMAP interconnect.
DCR read може впливати на ordering/timing, тому pilot не зливається зі61.

Окремий N95 native61 D2 calculation тепер використовує виміри саме цього
cohort: [scenarios](evidence/2026-10-04/ring-candidates-n95-native61-calculation.json).
Batch15 exchange p50=5249us проти old54=2716us; raw DSP timer p50=86778
проти44044 ticks. Batch1/2 близькі, великі8/15 повільніші. Сам Wi-Fi чи
демон не пояснює збільшений інтервал усередині DSP. Частоти brackets
не є continuous trace; WPE історичних runs невідомий. Причина не доведена.
Synthetic transform не є application kernel. WSOLA наступним окремим63
уже виміряно: [WSOLA ring/A](N95_WSOLA_RING_2026-10-04.md). MDEC/SPU
ring kernels ще не виміряні; емулятор unchanged. E90 відкладено до завтра.
