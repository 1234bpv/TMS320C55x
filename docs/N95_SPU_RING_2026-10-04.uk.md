# N95 SPU67: точний plain-mix job через кільце

**Для виміряного блокувального plain-mix job залишити ARM.** N95 виконав
24 pilot jobs і 1080 full jobs у трьох серіях для 1/8/24 голосів,
по64 семпли кожного голосу. Усі128 stereo accumulator words кожного job
точно збіглися з independent Python oracle й actual ARM assembler;
усі сторінки, ownership, headers, padding та lifecycle пройшли перевірки.
Жоден із1080 full jobs не мав `H+D<A` навіть без setup.

Це **plain mix після ADSR**, а не весь SPU: ADPCM decode, envelope/noise,
pitch/fmod, reverb, capture, SPU RAM, DMA/register/IRQ ordering та final
PCM лишаються поза job. Емулятор не змінювався; E90 не опитувався.

360 jobs кожного розміру,45 кожного із8 fixtures. `H+D` починається
перед packing і закінчується після реконструкції всіх128 sums у ARM
memory. Включає input packing, cache operations, обидва notifications
і DSP calculation. Oracle/header/padding/input-unchanged checks поза
цією межею. Notification-only p50=1312.256/2502.441/2624.512us не є
чистим DSP `D`; raw DSP ticks та counts_per_ms не перетворювали у ms.

`A` — actual current HAVE_ARMV5 mixer із `smlawb/smlawt`, усереднено
256 послідовних additions до warm sums. Reset, single-job oracle та
modular256-job oracle поза A; voice wrapper/loop і volatile sink усередині.
Є одна ABI adaptation: global ChanBuf load замінено п'ятим pointer
argument; арифметичні інструкції збережені. Live emulator cache/state
відрізняється від isolated probe. ARM-before/after чергується по jobs.

A min/max для1/8/24 голосів:3.576–16.332/13.471–44.346/
40.412–98.109us. Розкид retained у pooled/per-case evidence. Вісім stock
clock brackets є snapshots, а не continuous DVFS trace; причину зміни
часів усередині серії ці виміри не встановлюють. Профіль не змінювали.

## Контракт даних й арифметика

Ring16KiB TOTAL:1024B control,15 input і15 output slots512B, по480B
payload/slot. Input містить128 initial32-bit sums,64 samples32 кожного
голосу та left/right volume32. Output —128 sums32. 24-voice input6848B
майже вичерпує7200B input payload. Pointers через DSP не передаються.

Python oracle відтворює packed OR/shift гучності, signed high-product
SMLAW та modular32-bit accumulation, включно зі spill від negative
left-volume. DSP використовує native MPY/MAC decomposition32×16;
40-bit C55 long-long не заміняє потрібний signed48-bit product. ROM
`__mpyli` не імпортується; усі15 imports є в збереженому N95 baseimage.
Fixtures охоплюють zero, signed16 edges, sparse/random samples,
negative/fractional/zero gains, initial sum wrap32. Два fixtures додатково
перевіряють full signed32 samples і volumes поза legal PCM range.
Це synthetic correctness coverage, не captured gameplay і не exhaustive
proof для всіх можливих inputs.

У full series перевірено138240 stereo sums32 і2672640 ring words16;
pilot24 jobs обліковано окремо. Перед/після кожного job DCR port0200
тільки читався:2160 readings0000/WPE0. Audit перевіряє зібрані helper bytes
`A45102004804` без relocations/writes. DCR reads можуть впливати на
ordering; independent OMAP2420 external-memory publication contract
лишається відкритим. Успішні fixtures не закривають його.

## Setup й асинхронні сценарії

Instrumented `S=setup+teardown`:p50=863494us, min817107/max1203368us,
9 full runs. Включає lifecycle journaling, не minimum production startup.
Useful independent ARM `W=0`; CPU usage не вимірювали (`-1`).

Strict formula: `max(H+D,W)+S/N < A+W`, тобто одночасно
`S/N<A` і `W>H+D+S/N−A`. Для N16/64/256/1000 перша умова не пройшла
в жодному job. Навіть умовний N1000000, де вона пройшла у всіх1080,
не дає blocking gain; p50 required W для1/8/24 voices приблизно
1614.750/3269.419/3500.830us. Це лише арифметичні thresholds,
не виміряна independent work і не доказ окупності resident/asynchronous SPU.

Повна SPU RAM512KiB та state coherency потребують іншої межі job:
[ABI/capacity audit](N95_SPU_BOUNDARY_2026-10-04.md). Historical scene3.7%
budget не підміняє actual A цієї проби. Повна PCM/state equivalence
залишається невиміряною; переносити весь SPU зараз підстав немає.
