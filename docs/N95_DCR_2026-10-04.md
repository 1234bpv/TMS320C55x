# N95: read-only DCR diagnostic

N95 ran a separate host47/candidate62/protocol39 pilot: 8 exchanges of 15 slots
each, 120 fully correct packets. Before and after each exchange, the DSP read I/O
port 0x200. All 16 values are **0000**, WPE(mask 80)=0. This is the current
measurement of the non-posted configuration; we do not attribute it to the
historical 54/61 runs. The DSP/PRCM configuration was not changed.

In the loadable DOFF, the helper `_ring_read_dcr` contains exactly 6 bytes
`A45102004804`: `MOV port(#0x200),T0; RET`. The helper has no relocation; the
compiler assembly calls it before and after ring_exchange and writes the results
into notification words 14/15, with marker dc01 in word 13. Protocol 39
distinguishes diagnostics from the ordinary 38. The host and the runner allow
this mode only on N95; the validator checks all frames, the marker, the WPE decode
and the lifecycle.
[Instruction audit](evidence/2026-10-04/n95-dcr62-instruction-audit.json),
[artifact proof](evidence/2026-10-04/n95-dcr62-artifacts.json).

Stock PRCM brackets PASS before/after; native pages unchanged, full-word checks,
wrap/carry, delete/free task/unmap/unreserve/free buffers/close/FINAL0/EXIT0.
After the pilot, the N95 originals 5 were restored and verified GET/SHA-equal;
PS 0. The daemon startup tuple 62209 did not change. `startTick` is not the phone
boot ID. [Measurement/restoration](evidence/2026-10-04/n95-dcr62-results.json).

D1 remains in_progress: the current WPE is already measured, but the full
OMAP2420 endpoint-memory/notification ordering contract is not yet proven.
[TI BIOS GBL reference](https://software-dl.ti.com/targetcontent/legacy_files/targetcontent/bios/bios_5_31/sabios-h16/docs/packages/ti/bios/doc/spru404m.pdf)
identifies the posted/non-posted selection for OMAP2420; the OMAP2420 TRM
SWPU064 is needed for the exact endpoint contract. The OMAP2423 public addendum
SWPU087C only refers the DSP chapter to the 2420 TRM. Other C55x EMIF manuals are
not evidence for this particular OMAP interconnect. A DCR read may affect
ordering/timing, so this pilot is not merged with 61.

A separate N95 native61 D2 calculation now uses the measurements of exactly this
cohort: [scenarios](evidence/2026-10-04/ring-candidates-n95-native61-calculation.json).

or the daemon does not explain the increased interval inside the DSP. The
