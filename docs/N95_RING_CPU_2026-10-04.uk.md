# N95: CPU-вартість усього ring window

Після [калібровки лічильника](N95_CPU_COUNTER_2026-10-04.md) новий
candidate64/host49/protocol38 завершив pilot120 packets і три повні серії
batch1/2/8/15:12 runs,9360 packets. Усі слова, wrap/carry, native pages,
ownership і teardown правильні; шість stock clock snapshots PASS.
[Результати/журнали](evidence/2026-10-04/n95-ring-cpu64-results.json).

CPU baseline знято після settling User::After(1); final yield та обидва
GetCpuTime calls включені в outer wall. Усередині120-job window немає
Log Write/Flush, ARM reference baseline чи per-frame CPU reads. Журнал
записано з retained120-row array після виміру. CPU містить pack/cache,
notification calls, waits, повну input/output перевірку, bookkeeping і
final yield. Тому це вартість correctness harness, не pure wait CPU або
production workload. Final yield явно виміряний і не віднімається з
denominator CPU fraction. В усіх13 windows CPU вкладається в outer wall
із допуском два ticks (~61us) на quantization.

| Batch | Exchange p50, us | CPU / outer wall, weighted | Useful MB/s, exchange intervals | Useful MB/s, full window |
|---:|---:|---:|---:|---:|
| 1 | 915 | 45.37% | 1.012 | 0.712 |
| 2 | 1190 | 45.87% | 1.474 | 0.960 |
| 8 | 3021 | 48.09% | 2.472 | 1.357 |
| 15 | 5126 | 45.68% | 2.834 | 1.500 |

Корисні двобічні bytes —480 payload bytes ×2×packets. Exchange інтервал
починається після pack, закінчується після completion/cache invalidate;
full window також включає pack/full-word checks/final yield. Ці два
throughput визначення не взаємозамінні. Useful parallel ARM W=0.
Per-frame CPU field=-1 означає відсутність виміру, не negative CPU usage.

DSP64 перебудований із поточного джерела, його SHA відрізняється від
історичного52/61; typed files/archive старих cohorts не замінені. Тому
нові performance samples окремі. У64 DCR не читається, WPE цьому cohort
за pilot62/WSOLA63 не приписується. DSP raw ticks не перетворено в ms.
Частоти brackets — snapshots, continuous DVFS trace/performance reservation
немає. Прискорення application kernel цей synthetic transform не доводить.

N95 CPU criterion тепер має вимір із каліброваними boundaries та явно
обмеженим scope; старі short-delta percentages лишаються unqualified.
Independent OMAP2420 endpoint-publication contract досі відкритий, D1/D2
загалом in_progress. MDEC/SPU actual ring kernels та application W не
виміряні; WSOLA63 негативний blocking verdict залишається окремим.
